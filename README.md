# Python-Machine-Learning-Deep-Learning-YT-Tutorials
# Learn with Dr. Jyoti: Python, Machine Learning & Deep Learning

Welcome to the official GitHub repository for **Learn with Dr. Jyoti**!

This repository contains Google Colab notebooks, practical coding examples, and hands-on tutorials to help students and beginners learn Python, Machine Learning, and Deep Learning step by step.

All notebooks are designed to support my YouTube tutorials, making it easy to follow along, practice coding, and build your own projects.

## Repository Structure

### 1. Python

Learn Python programming fundamentals and essential libraries used in Data Science and Machine Learning.

Topics include:

- 1.First Python Program covering loops, lists, strings, tuples, dictionary
- 2.Functions in Python
- 3.Python Modules
- 4.NumPy
- 5.Pandas
- 6.Matplotlib
- 7.Seaborn

### 2. Machine Learning

Learn the complete Machine Learning workflow, from data preprocessing and exploratory data analysis to model training, evaluation, and clustering.

Topics include:

- 1.Data Preprocessing and Exploratory Data Analysis (EDA)
- 2.Classification with Logistic Regression
- 3.Customer Churn Prediction
- 4.Classification Evaluation Metrics: Accuracy, Precision, Recall and F1-Score
- 5.Overfitting, Underfitting and Cross-Validation
- 6.Feature Engineering for Customer Churn
- 7.Comparing Classification Models using the Wine Dataset
- 8.Linear Regression with Regularization
- 9.Polynomial Regression
- 10.Principal Component Analysis (PCA)
- 11.K-Means Clustering
- 12.Hierarchical Clustering using Iris
- 13.DBSCAN Clustering with Two Moons
- 14.Customer Segmentation using Clustering

### 3. Deep Learning

Learn Deep Learning concepts through practical Python and PyTorch implementations, starting with basic neural networks and progressing to Convolutional Neural Networks (CNNs).

#### Tutorial 1: Single-Layer Perceptron in Python
Understand the fundamentals of a perceptron and how a simple neural model makes predictions.

#### Tutorial 2: Your First Complete Neural Network — Breast Cancer Classification with PyTorch
Build your first complete neural network using PyTorch for a binary classification problem.

#### Tutorial 3: Training Loop in PyTorch — Breast Cancer Classification
Understand how a neural network learns through forward propagation, loss calculation, backpropagation, and weight updates.

#### Tutorial 4: Mini-Batches, Validation and Loss Curves — Breast Cancer Classification
Learn mini-batch training, validation, and how to plot and interpret training and validation loss curves.

#### Tutorial 5: Your First CNN in PyTorch — Fashion-MNIST
Build a Convolutional Neural Network to classify clothing images from the Fashion-MNIST dataset.

#### Tutorial 6: How to Improve CNN Accuracy in PyTorch
Explore practical techniques to improve CNN performance, train better models, and evaluate classification accuracy.

## How to Use the Notebooks

1. Browse the topic you want to learn.
2. Open the corresponding `.ipynb` notebook.
3. Click the **Open in Colab** badge if provided, or use the notebook's GitHub URL with Google Colab.
4. In Google Colab, select **File → Save a copy in Drive**.
5. Run the code cells one by one and experiment with the examples.
